# ShadowBlog

A responsive study blog with code-based private chat. Requires Node.js 18+
with no build step. Run `npm install` and `npm start`, then visit
`http://localhost:3000`. Set `DATABASE_URL` for persistent storage and
`ADMIN_PASSWORD` for the owner account. See [FIX.txt](FIX.txt) for Render
setup, private commands, and backup instructions.
